# GitHub 发布与私有演示部署

GitHub 保存代码。GitHub Pages 是静态站点服务，不能直接运行此 Python 多进程应用：[官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)。

## 本地启动

使用 Python 3.12 创建独立环境，安装根目录 `requirements.txt`，执行 `python -m SmartVoyage.services.stack`。

页面为 `http://127.0.0.1:8501`。内部 5005 / 5006 / 5007 为领域 Agent，8001 为 MCP。启动器检查端口冲突，不结束其他程序；Ctrl+C 回收本次启动的进程。默认不调用付费模型。

## 私有服务器演示

Docker 将协议服务放在容器内部，仅发布页面；数据卷保存模拟订单。

1. 在服务器克隆仓库。
2. 复制 `.env.example` 为 `.env`，填写自己的随机访问口令（至少 12 字符）。规则模式无需模型密钥。
3. 执行 `docker compose up -d --build`。
4. 在自己电脑建立隧道：`ssh -L 8501:127.0.0.1:8501 用户名@服务器地址`。
5. 浏览器打开 `http://127.0.0.1:8501`，输入口令。

通过域名邀请他人访问时，在服务器增加支持 WebSocket 的 HTTPS 反向代理，指向 `127.0.0.1:8501`。不要开放 5005–5007 或 8001。访问口令只是私有演示门禁，不是用户账户或完整限流系统；付费 LLM 需控制访问范围。

LLM 模式在 `.env` 设置 `SMARTVOYAGE_MODEL_MODE=llm` 和模型变量，再重建容器。`.env` 不上传。模型费用由所接服务商决定。

## 发布包

在完整本地工作区执行 `python scripts/export_travel.py`，按允许清单生成 `release/SmartVoyage`。上传此目录内的内容，不上传整个学习工作区。导出脚本属于本地发布工具，不随精简包发布。

不包含旧配置、SQL、日志、数据库、虚拟环境、ResolveDesk 或学习目录。导出时检查常见密钥模式及旧配置中的敏感字符串，只报告文件和规则，不输出秘密。

GitHub Actions 在 Linux / Python 3.12 安装依赖并验证。云端 CI 与本地测试结果分开报告。

## 验证限制

本机有 Docker 客户端但引擎未运行，容器构建仍需在可用环境验证。未提供服务器账户或域名，提交 GitHub 不等于已有公网应用地址。

MCP 测试使用官方 SDK 客户端与服务端经 Streamable HTTP 连接，不是函数直接调用。SDK：[modelcontextprotocol/python-sdk](https://github.com/modelcontextprotocol/python-sdk/tree/v1.x)。可选天气提供者：[Open-Meteo](https://open-meteo.com/en/docs)。
